The right-size review

A short, fixed-fee engagement before money is committed. It works for a new project, a tender being drafted, or a system that's already running and costs too much.

  1. Read the plan

    The project document, tender specification, or the system as it runs today.

  2. Measure the need

    Real users, transactions, data volumes, uptime and security requirements, measured where we can and estimated where we can't.

  3. Map to reuse

    The agency's own retired devices first, then our reconditioned stock, and new equipment only where nothing else will do.

  4. Compare

    New, reused and mixed options side by side: cost, power use, expected life, risk and how each option meets the rules.

  5. Hand over

    A report and a right-sized specification your team can use directly in e‑GP tender documents.

Independence: we can be hired only as reviewers and step aside from supplying that project, so the review is never a sales pitch. We agree a fixed fee in advance and take no commission on what you buy afterwards.

What often gets right-sized

  • Servers sized for a peak that never comes, replaced by smaller mirrored nodes that can grow when the load does
  • New desktops for data entry, kiosks or classrooms, replaced by reconditioned laptops and desktops
  • New displays for notice boards and queue screens, replaced by reused monitors and TVs
  • Low-traffic portals hosted round the clock in a data centre, while restricted data stays in national facilities
  • One large purchase up front, replaced by phases that follow measured use

These are patterns we look for, not findings about any particular project.
